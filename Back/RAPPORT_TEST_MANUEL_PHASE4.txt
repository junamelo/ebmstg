3. VÉRIFICATIONS TECHNIQUES VIA API (optionnel mais recommandé)
================================================================================

Requête 1: Vérifier le statut des factures après import
-------------------------------------------------------
curl -H "Authorization: Token <agent_token>" \
  http://127.0.0.1:8000/api/billing/invoices/?numero_facture=A20260601041-99475555

ATTENDU: {"statut": "VALIDEE", "fichier_pdf": "..."}

Requête 2: Essayer d'accéder à la facture en tant qu'employé AVANT publication
-----------------------------------------------------------------------------
curl -H "Authorization: Token <marie_token>" \
  http://127.0.0.1:8000/api/billing/invoices/<invoice_id>/

ATTENDU: 404 NOT FOUND (si non publiée) ou 200 OK (si déjà publiée)

Requête 3: Publier la facture via API
------------------------------------
curl -X POST \
  -H "Authorization: Token <agent_token>" \
  http://127.0.0.1:8000/api/billing/invoices/<invoice_id>/publier/

ATTENDU: 200 OK, {"statut": "PUBLIEE"}

Requête 4: Accéder à la facture APRÈS publication
------------------------------------------------
curl -H "Authorization: Token <marie_token>" \
  http://127.0.0.1:8000/api/billing/invoices/<invoice_id>/

ATTENDU: 200 OK avec tous les détails de la facture
