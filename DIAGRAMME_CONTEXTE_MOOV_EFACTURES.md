# Diagramme de contexte actuel

Le diagramme de contexte présente le portail Moov e-Factures comme le système central. Il distingue les acteurs qui utilisent l'application des services techniques avec lesquels elle échange des données : PostgreSQL, le stockage des PDF, Garnet, Celery, le service SMTP et le système de facturation Moov Africa.

Le fichier PlantUML correspondant est `DIAGRAMME_CONTEXTE_MOOV_EFACTURES.puml`.
